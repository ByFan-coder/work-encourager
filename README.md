# 上班鼓励器 · SV版

一个轻量的 Windows 便携桌面工具，显示上班收入、下班倒计时、工时进度和手动加班计时。

## 运行

适用于 Windows 10 / 11，使用系统自带的 .NET Framework 4.x，无需安装额外运行环境或联网。

从本仓库的 Releases 下载便携 ZIP，解压整个文件夹，双击 `上班鼓励器.exe`。

也可以下载源码，双击 `重新编译.cmd`，使用 Windows 自带的 C# 编译器生成程序。

## 功能

- 月薪按当月实际排班工作日折算，跨月自动重算。
- 支持自定义每周工作日，以及节假日、调休的逐日排班调整。
- 收入自动计时、下班倒计时、工时进度、暂停与继续。
- 手动开始及结束加班，每次按 0.5 小时向下取整。
- 加班倍率：工作日 0.75 倍、周末 1 倍、法定节假日 1.5 倍，以开始时的正常时薪为基数。
- 加班收入计入今日、本月收入，记录保存在本地。
- 金额数字颜色自选、窗口置顶，标题栏显示蓝色“SV版”。

## 默认设置

| 项目 | 默认值 |
| --- | --- |
| 月薪 | 10000 元 |
| 每周工作日 | 周一至周五 |
| 上下班 | 09:30–18:15 |
| 午休 | 12:00–12:45 |
| 每天计薪时长 | 8 小时 |

日薪 = 月薪 ÷ 当月实际工作日数；时薪 = 日薪 ÷ 每天计薪小时数。
节假日、调休需要自行调整排班和加班类型。
本月正常班次累计按已过去的排班日满勤估算，扣除记录的暂停，再加上加班金额。

## 本地数据

`data.xml` 保存工资、排班、颜色、暂停和加班记录；`data.xml.bak` 保存上一次配置备份。
这些文件已加入 `.gitignore`，不会被常规 `git add` 提交。
更新程序时复制旧数据文件即可保留配置；没有数据文件时使用上述默认值。

完整的计时、跨夜班、加班及升级规则见 `使用说明.txt`。
